Шрифт Minecraft для редактора GUI (Spraute Studio)
==================================================

Положите сюда ОДИН файл шрифта с именем:

  minecraft.ttf
  или minecraft.woff2
  или minecraft.otf

Полный путь в проекте:

  app/public/fonts/minecraft.ttf

После добавления файла перезапустите Studio (npm run dev).

Подойдут популярные TTF-версии ванильного шрифта (Minecraftia, Minecraft Seven,
или конвертированный из assets/minecraft/font). Для кириллицы нужна версия с
русскими глифами — не все скачанные шрифты её содержат.

Если шрифт не найден, редактор использует monospace как запасной вариант.
